# Inventory Management System

A console-based inventory management app built in Java.

## Features
- Add new items (ID, name, price, stock)
- Remove items by ID
- Display all inventory items
- Input validation and error handling

## Tech Stack
- Java (Core)
- OOP — Classes, Objects, Repository Pattern

## How to Run
javac Main.java
java Main
